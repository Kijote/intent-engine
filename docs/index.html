Este playground usa un clasificador TF-IDF + regresión logística de n-gramas de caracteres entrenado en memoria con un corpus pequeño. No es todavía el modelo TF-IDF + regresión logística de la PoC anterior. Sirve para experimentar dentro de GitHub sin compilación ni servicios.

Los valores son puntuaciones del modelo, no probabilidades calibradas. Ninguna acción se ejecuta automáticamente.
